# Howl: notes for AI helpers

## The project
Howl is a social app for NC State students to share short posts about campus life. It is a web app built with Vite and React. The design has not been decided yet, so the app is intentionally plain, with no colors, fonts or styling.

## Where things are
- `src/App.jsx` is the page.
- `src/posts.js` holds the sample posts (15 of them, one very long, one with no location).
- `explorations/` is for design ideas, in numbered rounds (`01`, `02`, `03`…). Work there never changes the real app. See `explorations/README.md`.

## About the owner
The owner is a designer who is a beginner and does not use the terminal. Please:
- Do the technical work (commands, installs, git) yourself.
- Explain anything technical in one short sentence.
- Don't ask technical questions. Choose sensible, beginner-friendly options.
- Stop and tell them exactly what to click when a website needs them (signing in, approving), and wait for "done". Never type their passwords.
- Don't add styling to the real app unless asked.

## Running the app
`npm install` once, then `npm run dev`. It opens at http://localhost:5173.
